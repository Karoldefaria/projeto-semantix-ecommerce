# Análise, Segmentação e Previsão de Vendas em um E-commerce Brasileiro

## Visão Geral

Este projeto foi desenvolvido como parte do Projeto de Parceria da EBAC com a Semantix.

O objetivo foi aplicar técnicas de Ciência de Dados e Machine Learning em um cenário real de comércio eletrônico utilizando dados públicos do marketplace Olist.

## Problema de Negócio

Empresas de e-commerce geram grandes volumes de dados diariamente. Entretanto, transformar esses dados em informações estratégicas continua sendo um desafio.

Este projeto busca responder:

**Como identificar perfis de clientes e prever o valor das compras futuras utilizando dados históricos de vendas?**

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

O conjunto de dados contém:

* Clientes
* Pedidos
* Produtos
* Vendedores
* Pagamentos
* Avaliações

## Técnicas Aplicadas

* Estatística Descritiva
* Probabilidade
* Inferência Estatística
* PCA
* K-Means
* Regressão Linear
* Decision Tree
* Random Forest
* XGBoost
* Cross Validation

## Principais Resultados

* Receita superior a R$ 16 milhões
* Ticket médio de aproximadamente R$ 161
* Segmentação de clientes em quatro grupos
* Modelos preditivos capazes de estimar o valor das compras

## Tecnologias

* Python
* Pandas
* NumPy
* Scikit-Learn
* XGBoost
* Matplotlib
* Seaborn

## Conclusão

A utilização de Machine Learning permitiu identificar padrões relevantes de consumo e criar modelos capazes de apoiar decisões estratégicas em operações de comércio eletrônico.
